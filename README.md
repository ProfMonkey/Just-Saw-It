# Just-Saw-It「刚刚刷到」🐒

> 一个轻量的电脑端工具：帮你找回“刚刚刷到、却因为刷新而消失”的信息流内容。

## 🎯 为什么做它？

在知乎、小红书这类信息流平台里，经常会出现一种情况：

```
刚刚看到一个很有意思的内容
        ↓
误触下拉刷新 / 页面刷新
        ↓
推荐流变了
        ↓
刚才那条内容找不到了
```

「刚刚刷到」就是为这个瞬间做的。

它不是用来保存你浏览过的一切，而是优先解决一个很具体的问题：

> **刷新之前刚刚看到的内容，刷新以后还能不能找回来？**

## 🧠 两种记录模式

### 🔴 刷新保护

这是项目当前最核心的模式。

打开信息流后，会先保存首屏当前可见的卡片一次；之后不会因为你一路向下浏览就不断保存大量历史。刷新前会临时保存当时视口，确认发生真正的页面 reload 后，再把刷新前新增的卡片加入历史。

程序重点关注：

> **如果你刷新了，现在屏幕上的内容能不能在刷新后找回来？**

适合：

> “我只是怕刚才看到的东西被刷新没了。”

### 🟢 自动记录

持续检测新的可见内容。

适合：

> “我希望把刚刚刷到的新内容持续留下来。”

## 🛠️ 安装

本项目目前是**电脑端 Tampermonkey Userscript 原型**，不是独立浏览器扩展，也不是 Android App。

### 1. 安装 Tampermonkey

在 Edge 或 Chrome 中安装 Tampermonkey（油猴）。

### 2. 安装脚本

打开仓库里的 'just-saw-it.user.js'。

复制完整代码，粘贴到 Tampermonkey 的新脚本中，然后：

```text
Ctrl + S
```

### 3. 打开网站

打开：

- 知乎首页
- 小红书首页 / 探索页

脚本生效后，页面右下角会出现：

```text
🐒 历史
```

## 🧪 推荐测试方法

### 测试知乎刷新保护

1. 打开知乎首页
2. 点击「🐒 历史」
3. 清空历史
4. 选择「刷新保护」
5. 保持当前页面不动几秒
6. 刷新知乎
7. 打开「🐒 历史」
8. 检查刷新前看到的推荐内容是否还能找到

### 测试知乎滚动

1. 清空历史
2. 保持「刷新保护」或切换到「自动记录」
3. 向下滚动
4. 查看历史中是否出现新的可见推荐内容
5. 检查不会一次保存大量屏幕之外的卡片

当前知乎 extractor 的策略是：

> **只处理当前视口内的卡片，并最多取 7 张。**

### 测试小红书刷新保护（V0.3.5）

1. 在 Edge 中打开小红书网页版的推荐 / 探索信息流。
2. 点击「🐒 历史」，清空历史并选择「刷新保护」。
3. 确认当前屏幕上能看到多篇笔记，记住其中 2–3 篇标题。
4. 按 `Ctrl + R` 刷新页面。
5. 再次打开历史，确认刷新前的笔记标题、卡片文字和来源链接能够找回。
6. 检查历史中没有导航栏、登录提示或整页拼接文字充当笔记。
7. 切换「自动记录」，向下滚动一屏，检查新出现的可见笔记能否记录，且同一篇不会反复新增。
8. 如果某些笔记没有标题、链接或封面，请截图并反馈；不要据此直接扩大选择器到整个页面。

小红书当前只从 `section.note-item` 提取笔记，最多处理视口内 15 篇；优先读取标题链接与封面图片。**代码已实现，但只有完成上述 Edge 实测后，才能确认选择器适配了你当前看到的小红书页面。**

## 🔐 隐私

当前版本使用 Tampermonkey 的本地存储能力保存历史。

项目本身：

- 不需要账号
- 不需要服务器
- 不主动上传历史内容
- 不需要云同步
- 不主动读取私信
- 不主动读取聊天内容
- 不处理个人中心
- 不处理文章详情页

不过，脚本保存的是网页上实际显示的内容，因此历史记录中仍可能出现网站展示的个人信息。

**不要在公共电脑上保存敏感内容。**
