# Just-Saw-It | 刚刚刷到 🐒

A lightweight local browser userscript for recovering text from social-media feeds after they refresh.

**状态：V0.1 电脑端技术原型（尚未在真实网页完成验证）**

## 能做什么

- 仅在知乎网页版首页、小红书网页版首页或探索页运行。
- 每约 2 秒检查一次页面文字变化，并保存历史快照。
- 通过页面右下角的「🐒 历史」按钮查看、复制历史文字。
- 可设置保留 1～100 条快照，暂停、继续、清空、立即记录。
- 记录保存在浏览器的 Tampermonkey 本地脚本存储中，不由该脚本主动上传到服务器。

## 安装

1. 在 Chrome 或 Edge 中安装 **Tampermonkey**（油猴）扩展并启用用户脚本支持。
2. 打开本仓库中的 [just-saw-it.user.js](./just-saw-it.user.js)。
3. 将完整代码复制到 Tampermonkey「添加新脚本」的编辑器中，保存（Ctrl+S）。
4. 打开知乎或小红书的网页版首页；如果脚本生效，右下角会出现「🐒 历史」。
5. 等几秒钟后刷新首页，打开「历史」检查能否找回之前的页面文字。

## 已知限制

- 只记录网页当前渲染的文字，**不保存图片、链接和完整文章**。
- 当前不会过滤广告、导航文字或重复的非关键信息。
- `innerText` 可能包含当前屏幕范围以外、但已经渲染的内容。
- 每 2 秒轮询一次；短时间出现又消失的内容可能漏记。
- 网站结构、登录状态和浏览器扩展限制可能影响实际效果。
- 本项目是验证原型，不保证在所有版本的知乎、小红书页面有效。

## 隐私

脚本仅对预设的两个网站生效，使用 Tampermonkey 的 `GM_getValue` 和 `GM_setValue` 在本地保存数据。保存的文字可能包括网页上展示的个人信息，请避免在共用电脑上保留敏感快照，并定期清理。
